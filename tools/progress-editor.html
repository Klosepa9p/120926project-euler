Project Euler Progress Editör

Çözdüğün problemin üstüne tıkla (yeşil = çözüldü), sonra "GitHub'a Gönder" butonuna bas. GitHub Actions birkaç saniye içinde euler-progress.svg'yi otomatik güncelleyip commit'ler — dosya indirip taşımana gerek yok.

⚙️ GitHub ayarları (ilk kurulumda bir kere doldur, tarayıcı hatırlar)

Token nasıl alınır: GitHub → sağ üstteki profil fotoğrafı → Settings → alt kısımda "Developer settings" → "Personal access tokens" → "Tokens (classic)" → "Generate new token (classic)" → bir isim ver, süre seç (örn. 90 gün), sadece "repo" kutucuğunu işaretle → oluştur → çıkan değeri (bir daha gösterilmez!) yukarıya yapıştır. Bu token sadece bu tarayıcıda, bu bilgisayarda saklanır; kimseyle paylaşma.
